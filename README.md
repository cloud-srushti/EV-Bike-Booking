# 🚴 **EV Bike Booking & Info Platform on AWS**
A cloud-based static web application for exploring and booking Electric Bikes (EV Bikes).
This project demonstrates hosting a static website on AWS using S3 and improving performance with CloudFront CDN.
---

# 🚀 **Project Overview**
The **EV Bike Booking & Info Platform** is a static website hosted on AWS that provides:
- EV bike information and details
- Bike booking interface
- Fast and secure content delivery
- Scalable cloud hosting architecture
The project focuses on AWS cloud deployment and static website hosting best practices.
---

# ☁️ **AWS Services Used**
**Amazon S3**– Static website hosting
**Amazon CloudFront** – CDN for faster global delivery
**IAM** – Secure access management
**Bucket Policy** – Public access configuration
---

# 🛠 **Features**
Static website hosted on AWS S3
Public access configuration using bucket policies
CloudFront integration for low-latency performance
Responsive frontend design
Scalable and cost-effective architecture
Improved website security and caching
---

# 📂 **Project Architecture**
User → CloudFront CDN → AWS S3 Bucket → Static Website Files
---

# ⚙️ **Deployment Steps**
1️⃣ **Create S3 Bucket**
- Create an S3 bucket
- Enable static website hosting
- Upload website files
2️⃣ **Configure Bucket Permissions**
- Disable block public access
- Add bucket policy for public read access
3️⃣ **Upload Website Files**
Upload:
- HTML
- CSS
- JavaScript
- Images
4️⃣ **Configure CloudFront**
- Create CloudFront distribution
- Select S3 bucket as origin
- Enable caching and HTTPS delivery
5️⃣ **Access Website**
Open CloudFront distribution URL in browser
